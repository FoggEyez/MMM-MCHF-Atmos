# Mirror Mischief

**MCHF = Mischief.** [Mirror Mischief](https://github.com/FoggEyez/Mirror-Mischief) is the collection and optional companion. The public companion installer is **not yet released**. Atmos runs independently using ordinary MagicMirror² configuration.

Existing companion users can install from this repository link and open Module settings. Choose the source, complete coordinates only for direct Open-Meteo access, then save and check the actual display. Unsupported/stale data produces no weather effect. Settings are literal defaults; one instance is supported.
