# Atmos troubleshooting

- Clear weather or missing/stale current observations intentionally show no effect. Run the companion setup check to distinguish configuration problems.
- Native weather must be enabled, type current, and metric or imperial. An optional weatherInstance must match the native instance.
- Direct Open-Meteo mode needs explicit coordinates and locationConfigured: true. Reduced motion and suspension keep effects still; lightning is opt-in.

Use the README for settings, dependencies, privacy and sources. For a bug report, include your device, MagicMirror and Node versions, the observed behavior and a minimal configuration with secrets removed. Do not post private feeds, tokens, precise home coordinates or network snapshots.
